# Calora AI — Server

AI-powered calorie & nutrition tracker with a Telegram Mini App frontend.
Snap a photo of your food, and Gemini Vision estimates the macros instantly.

## Features

- 📸 **AI food analysis** — photograph meals and get per-dish КБЖУ via Gemini 2.5 Flash
- 🎯 **Personalized daily goals** — Mifflin–St Jeor formula + Gemini adjustments for restrictions & conditions
- 🏆 **Gamification** — weekly quests generated by AI, streaks, progress tracking
- 💡 **Daily AI tips** — personalized nutrition advice based on your actual food log
- 💧 **Water tracking** — log water intake with daily targets
- ⚖️ **Weight history** — track progress over time with weight chart data
- 🤖 **Telegram bot** — `/start` command opens the Mini App via inline keyboard
- 🔐 **Telegram WebApp auth** — validates `initData` signature on every request
- ☁️ **Backblaze B2 storage** — food photos stored privately with presigned URLs

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | [FastAPI](https://fastapi.tiangolo.com/) |
| ORM | [Tortoise ORM](https://tortoise.github.io/) + [Aerich](https://github.com/tortoise/aerich) migrations |
| Database | PostgreSQL (via asyncpg) |
| AI | [Google Gemini 2.5 Flash](https://ai.google.dev/) (`google-genai`) |
| Telegram Bot | [aiogram 3](https://docs.aiogram.dev/) (webhook mode) |
| Object Storage | Backblaze B2 (S3-compatible, via boto3) |
| Config | [pydantic-settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/) (`.env` file) |
| Package Manager | [uv](https://docs.astral.sh/uv/) |

## API Reference

All endpoints (except `GET /` and `POST /webhook`) require the `initData` header
with a valid Telegram WebApp init string.

### Users
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/users/me` | Current user + profile + goals + onboarding status |

### Onboarding
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/onboarding/progress` | Current onboarding step & draft data |
| `POST` | `/api/onboarding/step` | Save one onboarding step |
| `POST` | `/api/onboarding/complete` | Finalize onboarding → create profile & goals |
| `DELETE` | `/api/onboarding/reset` | Debug: reset onboarding |

### Profile
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/profile` | Create profile directly (bypasses onboarding) |
| `PUT` | `/api/profile` | Update profile → recalculates DailyGoal |

### Food
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/food/analyze` | Upload photo → Gemini returns dishes[] with КБЖУ + `photo_key` |
| `POST` | `/api/food/log` | Save food log with items (pass `photo_key` from analyze) |
| `GET` | `/api/food/{date}` | All food logs for a date (YYYY-MM-DD) |
| `DELETE` | `/api/food/{log_id}` | Delete a food log |

### Water
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/water` | Log water intake (amount_ml) |
| `GET` | `/api/water/{date}` | Water logs for a date |
| `DELETE` | `/api/water/{log_id}` | Delete a water log |

### Weight
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/weight` | Last 90 weight entries (for progress chart) |

### Stats
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/stats/daily?date=YYYY-MM-DD` | Daily totals vs goals |
| `GET` | `/api/stats/active-dates?from=...&to=...` | Dates with logged data (for calendar) |

### Quests
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/quests` | Active quests |
| `POST` | `/api/quests/generate` | Generate 3 new weekly quests via AI |

### AI Tips
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/tips/today` | Today's tip (auto-generated if missing) |
| `GET` | `/api/tips` | Last 7 tips |

## Database Schema

```
users (PK: telegram_id)
 ├── user_profiles     1:1  biometrics, goals, restrictions
 ├── daily_goals       1:1  calculated КБЖУ targets
 ├── onboarding_drafts 1:1  wizard state (deleted on completion)
 ├── food_logs         1:N  meal entries (each has food_items[])
 │    └── food_items   1:N  individual dishes within a log
 ├── water_logs        1:N  water intake entries
 ├── weight_history    1:N  weight change records
 ├── quests            1:N  gamification quests
 └── ai_tips           1:N  daily AI advice (unique per user+date)
```

## Setup

### Prerequisites
- Python ≥ 3.9
- PostgreSQL
- [uv](https://docs.astral.sh/uv/) package manager
- Telegram bot token (via [@BotFather](https://t.me/BotFather))
- Google Gemini API key
- (Optional) Backblaze B2 account for photo storage

### 1. Clone & install

```bash
git clone https://github.com/dudha369/calora-ai-server.git
cd calora-ai-server
uv sync
```

### 2. Configure environment

```bash
cp .env.example .env   # then fill in values
```

Required variables:

```env
BOT_TOKEN=your-telegram-bot-token
DB_URL=postgres://user:pass@localhost:5432/calora
GEMINI_API_KEY=your-gemini-api-key
WEBHOOK_URL=https://your-domain.com
WEBAPP_URL=https://your-frontend-url.com

# Optional: Backblaze B2 (food photo storage)
B2_ENDPOINT=https://s3.us-west-004.backblazeb2.com
B2_KEY_ID=your-key-id
B2_APPLICATION_KEY=your-app-key
B2_BUCKET=your-bucket

# Optional: access control
WHITELIST_ENABLED=false
WHITELIST_IDS=123456789,987654321
ADMIN_TELEGRAM_ID=123456789
```

### 3. Run database migrations

```bash
uv run aerich upgrade
```

### 4. Start the server

```bash
uv run python .
```

The server starts on `http://localhost:8080` by default.
Set `APP_HOST` and `APP_PORT` in `.env` to customize, or use the `PORT` env variable.

### Development

```bash
ENV=development uv run python .
```

In development mode, CORS allows `localhost:5173` and `localhost:3000` in addition to `WEBAPP_URL`.
